## Reflection
Working on this redesign was both interesting and exciting because it gave me the chance to experiment with different ways of updating and enhancing my website. Each time I reloaded the pages, I could immediately see the changes play out, which made the process feel interactive and rewarding. One of the highlights was testing the site on mobile devices and comparing the layout to the desktop version. Seeing the contrast between the two really showed me the importance of responsive design and how CSS media queries can transform the user experience.

Another part of the process that stood out was deciding where and which comments to add in both the HTML and CSS code. It felt a little choicy at times, but it helped me think carefully about which sections needed explanation and documentation. This made me more aware of how comments can guide future readers of the code, including myself. Overall, going through the entire process was engaging because I was interacting with tools and techniques I hadn’t used before. It gave me a stronger understanding of how structure, responsiveness, and version control all come together to create a professional website.



# Personal Website JavaScript Enhancements
**Author:** Shemaah George  

## Project Overview
This is my personal website. It features interesting details about me that you do not know. It shares hobbies, skills, career interests, and even character traits of myself. I hope this leads to a slightly better understanding and insight of myself. 

## JavaScript Enhancements Summary
- **Dark Mode / Light Mode Toggle:** Added a toggle button in the navigation bar that switches a class on the element, overriding CSS custom color variables to switch between light and dark themes across all pages.

- **Time-Based Welcome Pop-Up Thing:** Added a script on the Home page that reads the user local system time and displays a pop-up greeting (*"Good Morning"*, *"Good Afternoon"*, or *"Good Evening"*) with a button to close it.

- **Back-to-Top Floating Button:** Added a floating button in the bottom-right corner that appears when scrolling down and smoothly scrolls back to the top of the page when clicked.

- **Show / Hide ("Read More") Content:** Added a toggle button in the *My Desired Career Path* section on the About page that reveals or hides extra details and updates the button text between *"Read More"* and *"Read Less"*.

- **Interactive Skill Guess (Dynamic Table Row):** Added an interactive form below the Skills table on the About page allowing users to submit a guessed skill, skill level, and enjoyment level.

## Redesign Summary
- Improved structure using semantic HTML elements .  
- Added responsive design with media queries for mobile, tablet, and desktop.  
- Organized files into logical directories.  
- Documented code with HTML, CSS, and JavaScript comments.  
- Used GitHub branching and Pull Requests for version control.  

## Technologies Used
- HTML5  
- CSS3 (CSS Variables, Flexbox, media queries)  
- JavaScript (DOM Manipulation, Event Listeners, Date Object)  
- GitHub (branching, commits, Pull Requests, GitHub Pages)  

## Directory Structure
The CSS file (`style.css`) is in its own `CSS` folder. 
The JavaScript file (`script.js`) is in its own `js` folder. 
The Image (`MindWalkerFire.jpeg`) is in its own `Images` folder. 
These 3 folders are within the `Personal-Website` folder as well. 
All 4 HTML files (`index.html`, `about.html`, `portfolio.html`, `contact.html`) and `README.md` are within the `Personal-Website` folder.


## Responsive Design Approach
- Used relative units (`%`, `rem`) and `max-width` for images and containers.  
- Applied media queries for screen widths at 768px (tablet) and 480px (mobile).  
- Ensured navigation and new JavaScript controls remain usable and adapt without horizontal scrolling.  

## Reflection
Enhancing my personal website with JavaScript was both interesting because it allowed for me to turn my regular website pages into something users can interact with. Putting in the five features: Dark Mode using CSS variables, the time-based welcome pop-up modal, the floating Back-to-Top button, the Read More toggle, and the interactive skill-guessing table row—gave me hands-on practice selecting HTML elements through the DOM and responding to click and scroll events.
